System Setup & Configuration

API Keys Configuration

Learn where and how to configure third-party API credentials for TripWise.

💡 Zero-Friction Out of the Box:
No API keys are required to run TripWise! Live weather and US AQI are fetched from Open-Meteo (100% free, no key required). Our built-in synthesis engine, curated places catalog, and payment sandbox work immediately with zero configuration.

Where to add your API keys:

Edit the environment file in your project directory at:

backend/.env Lines 15–17
1. GEMINI_API_KEY Optional

Powers generative AI travel advice and custom itinerary prompts via Google Gemini. If omitted, TripWise uses intelligent telemetry-grounded local synthesis with strict budget math.

Get free key: aistudio.google.com
2. GEOAPIFY_API_KEY Optional

Queries live Geoapify Places API for hotels, restaurants, fuel stops, and attractions. If omitted, TripWise serves from our pre-indexed verified database.

Get free key: geoapify.com
3. NEWS_API_KEY Optional

Fetches regional news and travel safety advisories. If omitted, TripWise synthesizes real-time safety advisories directly from Open-Meteo weather hazard codes.

Get free key: newsapi.org or GNews
# backend/.env snippet:
GEMINI_API_KEY=AIzaSy...your_gemini_key
GEOAPIFY_API_KEY=your_geoapify_key
NEWS_API_KEY=your_newsapi_key
